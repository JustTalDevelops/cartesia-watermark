# Joint TiCodec quality evaluation

This evaluates the already declared full-codec and middle-band development panel.
It does not choose outputs using the reference texts or change the original
19/44 result. No new recordings or detector requests are generated by this step.

`experiments/ticodec_panel_report.py` waits for all declared endpoint receipts,
including both positive controls and every candidate repeat. It revalidates the
complete generation inventory, exact files, request identities and pacing before
creating a reference plan. Every newly eligible treatment is scored, including
detector-positive files and identical-file treatment rows. The separately
qualified pilot keeps its original receipts and is not checked again.

Run reference inference after other neural jobs finish. The evaluator copies
the completed study's original transcription caches into its own directory,
disables HTTP, and uses the unchanged language-specific checkpoints and quality
criteria. Missing or incomplete measurements cannot qualify an output. Existing
work is never overwritten or automatically restarted.

```sh
python experiments/ticodec_panel_report.py score \
  --declaration /path/to/endpoint.declaration.json \
  --detector /path/to/detector.json \
  --evaluation /path/to/quality/evaluation.json

python experiments/ticodec_panel_report.py export \
  --declaration /path/to/endpoint.declaration.json \
  --detector /path/to/detector.json \
  --evaluation /path/to/quality/evaluation.json \
  --output /path/to/curated_report.json
```

The report retains all 75 generation rows, including processing rejections.
It counts distinct spent sources separately from treatments and repeated
requests. This is development evidence with zero fresh validation sources;
negative detector replies and estimated quality do not prove physical erasure
or universal reliability. Human listening approval remains unmeasured.
